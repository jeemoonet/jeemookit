# jeemookit 用户手册

> 在 Cursor 里用中文说话，完成：转稿 → 配图 → 导出 Word → 发飞书。

| 项目 | 内容 |
|------|------|
| 版本 | 1.4.0 |
| 读者 | 产品、运营、项目等非研发同学 |
| 前提 | 同事已装好 Cursor 与 jeemookit；你只需新开 Agent 对话 |

---

## 1. 能做什么

| 你想做的事 | 对 AI 说 |
|------------|----------|
| PDF 转成可编辑稿（扫描件也行） | 「把这份 PDF 转成 Markdown」 |
| Word 转成可编辑稿 | 「把这份 Word 转成 Markdown」 |
| 补流程图 / 架构图 | 「补一张流程图」/「画一张架构图」 |
| 加宣传场景图 | 「加一张用户场景宣传图」 |
| 交正式 Word | 「导出 Word」 |
| 发到飞书 | 「上传到飞书」 |
| 从飞书拉回本地改 | 「把这个飞书文档下载成 Markdown」 |

把**文件路径或飞书链接**一起发给 AI，效果更好。

---

## 2. 跟做一遍（最常用）

领导给了 PDF → 你改完交 Word：

1. 告诉 AI PDF 路径，说：**「转成 Markdown」**
2. 改内容；需要图就说：**「补一张流程图」**
3. 说：**「导出 Word」**，把生成的 `.docx` 发出去

要发飞书：定稿后说 **「上传到飞书」**，把链接丢群里即可。首次可能弹出浏览器，用飞书账号登录一次。

---

## 3. 有哪些能力（Skill）

不用记名称，需要时转给研发即可。

| Skill | 作用 |
|-------|------|
| `pdf-to-md` | PDF → 可编辑 Markdown（含扫描 OCR） |
| `word-to-md` | Word（.docx）→ Markdown |
| `txt-to-image` | 文档配图（流程/架构 Mermaid、宣传图） |
| `md-to-word` | Markdown → 正式 Word（图自动嵌入） |
| `md-to-feishu` | Markdown → 飞书云文档 |
| `feishu-to-md` | 飞书云文档 → 本地 Markdown |
| `jeemoo-init` | 写入项目协作约定（研发用，一般装好即可） |

技术细节见：[产品使用说明书](README.md)。

---

## 4. 小贴士

- 说目标就行，例如：「给我一份带流程图的方案 Word」。
- 先转稿 → 再改字 → 再配图 → 最后导出，少返工。
- 不要随便改图片文件夹名，否则 Word / 飞书里图会丢。
- 对外稿请自己核对专有名词和数据。
- AI 不会这些功能？请同事确认已安装，并**新开**一次对话再试。
